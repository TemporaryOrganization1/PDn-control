## Changes After Refinement

### New user stories
The following stories were added from the Product Backlog after the initial Assignment 2 elicitation:

- **US-11 — Account creation** (Must Have): users must be able to create an account before using the service. MVP1 prerequisite.
- **US-12 — Web interface (not CLI)** (Must Have): the system must expose a web UI rather than requiring CLI interaction. Enables all other web-dependent stories.
- **US-13 — Paid subscription plan management** (Must Have): users need to choose among paid subscription tiers.
- **US-14 — Account deletion** (Should Have): users can delete their account and associated data.
- **US-15 — Report sharing** (Could Have): users can generate a public link to share scan results without downloading the full PDF.

### Priority changes
- **US-07 — Risk-scoring display**: promoted from Should Have to Must Have based on team estimation and customer feedback captured in the Product Backlog.

### Removed stories
- **US-04 — Selectable violation list**
- **US-10 — Web-based admin control system**: removed because the product already targets a web-based interface as the primary delivery model. Originally marked as Won't Have, preserved only for traceability.
