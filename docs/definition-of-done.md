## What has to be done to mark issue as completed:
- All issue acceptance criteria are satisfied
- All required CI checks for the product stack pass successfully (build, lint, tests, and other pipeline validations)
- The work is reviewed by another team member
- Relevant automated tests are implemented and passing
- Relevant automated quality requirement tests are implemented and passing
- For user stories, the linked supporting PBIs provide the required implementation, review, and verification evidence
- Required tests or checks pass
- Verification and testing evidence is preserved in PRs/MRs, CI results, or linked documentation
- Visible changes has to be documented in CHANGELOG.md
