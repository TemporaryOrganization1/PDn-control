Скачать архив всех флагов стран

2. Задачи:
  - Посмотреть worker crawler тк там обновился API. Теперь сервис составляет отчет более подробно в JSON формате.
  - Приспособить все API и обработчики в main backend и frontned к новому API у worker crawler.
  - Переделать риск-скоринг на странице результатов. Он должен показывать не шанс штрафа, а сколько проверок выполнилось успешно - это если говорить простыми словами. 
  Как это работает: всего допустим 15 проверок. Каждая проверка при успехе дает 1 балл. При предупреждении дает 0.5 балла. При провале дает 0 баллов. 
  Риск-скоринг же считается по формуле round(КОЛ-ВО ПОЛУЧЕННЫХ БАЛЛОВ / КОЛ-ВО ВСЕГО ПРОВЕРОК * 100); Теперь 100% - это хорошо (зеленый) 0 % - плохо.
  - показывать предположетльную сумму штрафов для юр-лиц и физ-лиц отдельно. Брать данные о суммах штрафов за проверки он должен в одном месте так как эти
    данные будут периодически обновляться. Желательно в виде JSON структуру. Рассматривай Приложение 1 если нужен источник сумм штрафов для проверок.
  - показывать прикрепленные изображения к проверкам. тебе будут переданы ID изображении и тебе нужно просто показывать под проверкой как прикрепленное приложение. 
  Фото можно будет открыть на весь экран при нажатии или скачать.
  - показывать данные SSL в блоке на странице результатов. Смотри код crawler чтобы узнать типы и поля данных.
  - показывать содержимое "about" поле результатов как краткое описание проверки.
  - показывать скриншот сайта на самом верху страницы результатов. Оно может быть не на всю ширину.
  - обновить PDF-репорт. учитывать изображения и новые данные при генерации.
  - привязать PDF-репорт и ID репорта. при удалении репорта cоответсвующии PDF-репорт также должен быть удален. Смотри как работает привязка между изображениями и репортом.
  - В блоке География серверов должны показываться флаги стран. Флаги стран дожны быть предоставлены пользователем.
  - В блоке Информация о сайте также должно показывать гео и флаг страны. в резльутатах будет поле "country" содержащий ISO-код страны или null или unknown
