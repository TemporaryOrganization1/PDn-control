# LLM Usage Report

## Where AI was used:

1. **Frontend development** — Used Google AI together with Figma to generate frontend code.

2. **User stories** — Used AI to fill in the `user-stories.md` file. The user stories themselves were not modified; all AI output was double-checked and corrected where necessary.

3. **Go microservice & crawler integration** — Used AI to create a Go microservice and a service that combines two crawlers using Docker Compose and Go. Also used AI to write the `README.md` (with verification and edits), and to configure the Lychee Link Checker.

4. **MVP report** — Used AI to generate the `mvp-v0-report.md` file.

5. **API documentation** — Used AI to create `openapi.yaml`, `postman_collection.json`, and Swagger.

6. **This report** — Used AI (opencode) to translate and format this document into English based on the original Russian version.
